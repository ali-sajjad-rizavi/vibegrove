- React/TSX/JSX (`.tsx`, `.jsx`) - Cyan atom symbol
- JavaScript (`.js`) - Yellow JS badge
- JSON (`.json`) - Dark {} badge
- HTML (`.html`) - Orange <> badge
- CSS (`.css`) - Blue # badge
- SCSS (`.scss`) - Pink S badge
- Markdown (`.md`) - Blue M badge
- Python (`.py`) - Blue PY badge
- Rust (`.rs`) - Orange RS badge
- Go (`.go`) - Cyan GO badge
- YAML (`.yaml`, `.yml`) - Red Y badge
- Shell (`.sh`, `.bash`) - Green $ badge
- SQL (`.sql`) - Blue Q badge
- GraphQL (`.graphql`, `.gql`) - Pink diamond
